# P1-08 内联 asm 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `asm [volatile] ("tpl" : outputs : inputs : clobbers)` 语句在 lexer/parser/sema/codegen 全链路可用，宿主 x86-64 上经 LLJIT 可执行，语义对齐 GCC。

**Architecture:** `asm` 注册为 `TOKEN_ASM` 关键字；前缀表达式层（`parseUnaryImpl`）识别并构造 `AsmExprAST`（表达式节点，经 `ExprStmtAST` 作语句）；sema 置 void 类型并校验操作数（左值/标量/约束/模板转义）；codegen 用 `llvm::InlineAsm` + `CallInst` 发射，outputs 传地址、调用后 load 回写。约束/模板/方言透传 LLVM，编译器不解析约束语义（D2）。

**Tech Stack:** LLVM 19 (`llvm::InlineAsm`, `InlineAsm::AD_ATT`), C++17, gtest (`ctest`), LLJIT (宿主 x86-64)。

**Spec:** `docs/superpowers/specs/2026-10-10-p108-inline-asm-design.md`

## Global Constraints

- TDD 硬性：每任务先写测试并亲见失败（编译或断言失败），再实现，再运行通过。
- 全量回归：每任务结束运行 `ctest --test-dir build --output-on-failure`，全绿才提交；新增测试文件后先 `cmake -B build` 重配置（tests/CMakeLists.txt 用 GLOB_RECURSE）。
- 一任务一提交；`git add` 只列明确文件清单（禁止 `git add -A`）；`docs/superpowers/` 与 `Progress.md` 用 `git add -f`。
- 方言固定 `InlineAsm::AD_ATT`（x86-64 宿主基线）；约束语义（寄存器名/合法性）透传 LLVM，后端验证（D2）。
- asm 节点 `type = void`、`isLValue = false`；outputs 左值回写、整体不产生值（D3）。
- 模板 `%` 后必须为 `%` 或数字（`%%` 转义 / `%N` 操作数引用），否则 E2024；`%%`/`%N` 原样透传 InlineAsm。
- 模板必须是字符串字面量：解析层强制 `TOKEN_STRING`（非字面量 → `SynExpected`，GCC 一致）。

## Review Focus

- 输入 `asm volatile("nop")`（volatile 且零操作数）：InlineAsm 须 `HasSideEffects=true` + 零参数签名，不得崩溃。
- 输入 clobbers 仅 `"memory"`/`"cc"`：约束串拼成 `~{memory},~{cc}`，零参数 `FunctionType` 合法。
- 输入含 `%%` 的模板：不得误报 E2024，转义由 LLVM 消化。
- 输入 inputs 为非常量/非左值表达式（如 `x + 1`）：语义合法，codegen 传值。
- 输入多 output（`%0`/`%1` 按 outputs 先后编号）：解析与 codegen 编号一致，逐位写回对应左值。

static ExprAST* parseStmtExpr(const std::string& body) {
    std::string src = "int32 f() { " + body + " return 0; }";
    s_lastTU = parse(src);
    if (!s_lastTU || s_lastTU->declarations.empty()) return nullptr;
    auto func = dynamic_cast<FunctionDeclAST*>(s_lastTU->declarations[0].get());
    if (!func || !func->body || func->body->stmts.empty()) return nullptr;
    auto est = dynamic_cast<ExprStmtAST*>(func->body->stmts[0].get());
    return est ? est->expr.get() : nullptr;
}
